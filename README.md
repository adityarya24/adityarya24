## What I build

- **AI agents & multi-agent systems** — orchestration layers that share context, route tasks by capability, and keep agents from stepping on each other's files
- **MCP servers** — real-world tools (Google marketing data, Indian market data, Vedic astrology) exposed to coding agents over the Model Context Protocol
- **Automation** — headless browser flows, cron pipelines, Telegram control planes, and systemd/VPS services that run 24/7
